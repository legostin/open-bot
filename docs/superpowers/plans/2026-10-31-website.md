# Piomio website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static Piomio website on GitHub Pages whose main widget is the real web UI playing scripted chapters on a
demo hub in the browser, in English and Russian (spec: `docs/superpowers/specs/2026-10-31-website-design.md`).

**Architecture:** `packages/web` gets a second Vite entry (`demo.html`, `src/demo/`) that installs `fetch`/`WebSocket`
shims and a static service worker, runs an in-page demo hub typed with `@piomio/shared`, and a director that plays one
chapter script per feature. `packages/site` is a Vite + React + Tailwind 4 landing prerendered per language that embeds
the demo in an iframe and drives it with `postMessage`.

**Tech Stack:** Vite 8, React 19, Tailwind 4, wouter 3 (memory location), TypeScript 7, vitest 5, Playwright 1.64.

## Global Constraints

- Node ≥ 24.5; local TS imports use the `.ts` extension in Node-run scripts; `import type` for types.
- The app's own code (`packages/web/src` outside `src/demo/`) stays unchanged unless a seam is unavoidable.
- Nothing in the demo or the site requests anything outside the site's own origin (no fonts, analytics, APIs) at run time.
- Every user-facing string of the site and of the scenarios lives in a per-locale catalog (`en`, `ru`), same key set.
- Text for code and comments is English; RU content uses «ёлочки», EN “curly quotes”.
- All companies, addresses and letters are made up (`example.com`, `*.example`).
- Temp files only under `tmpdir()`; throwaway hubs and their data are deleted after use.
